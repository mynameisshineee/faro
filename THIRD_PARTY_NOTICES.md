## Why this file exists

The container image is built in two stages, and the second copies the compiled
web bundle out of the first. That makes the image a **redistribution** of the
JavaScript packages in that bundle, not merely a consumer of them — and the
permissive licences involved (MIT, ISC, Apache-2.0 §4(c)) require the copyright
and attribution notices to travel with the copy.

## What is still missing

1. Licence **texts** collected and shipped in the image next to the bundle, and
   committed here so a reader of the repository sees them too.
2. Declared licences measured for the exact Python closure in the image.
3. A check that fails the build when a runtime dependency arrives without a
   readable licence. Falsifier: add a dependency with the licence file removed —
   the build must go red.

Until (1) is done, this file documents the gap rather than closing it. Saying so
is the point: an inventory that looks complete and is not would be worse than
none, because nobody would go looking.
