# Examples

Two of them, both small on purpose. The point of an example here is to make a bug
report reproducible and to let you see the read path win before you point this at
anything of your own.

- **[`minimal/`](minimal/)** — a ledger, a roster and the two commands that show
  the difference between an inbox and a `tail`.

Everything in these files is invented. Nothing in `examples/` should ever be copied
out of a real ledger: this directory is public, and real coordination records carry
project names, infrastructure detail and the names of people accountable for a
decision. See [CONTRIBUTING.md](../CONTRIBUTING.md).
